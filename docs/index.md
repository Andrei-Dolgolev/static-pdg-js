# static-pdg-js Documentation

This directory contains comprehensive documentation for the static-pdg-js package.

## Available Documentation

- [Package Documentation](PACKAGE.md) - Comprehensive documentation of the package API and features
- [VS Code Extension Guide](VSCode_Extension_Guide.md) - Guide for integrating with VS Code extensions
- [Example Documentation](SAMPLE_README.md) - Documentation for the included examples

## Original Research

This code is based on research by Aurore Fass. For more details, see:

- [Dissertation](https://publications.cispa.saarland/3471/7/fass2020thesis.pdf) - Detailed explanation of the concepts
- DoubleX [paper](https://swag.cispa.saarland/papers/fass2021doublex.pdf) & [code](https://github.com/Aurore54F/DoubleX)
- HideNoSeek [paper](https://swag.cispa.saarland/papers/fass2019hidenoseek.pdf) & [code](https://github.com/Aurore54F/HideNoSeek)
- JStap [paper](https://swag.cispa.saarland/papers/fass2019jstap.pdf) & [code](https://github.com/Aurore54F/JStap)

## Documentation Descriptions

### Package Documentation (PACKAGE.md)

Comprehensive guide to using static-pdg-js as a Python package. Includes:
- Installation instructions
- API documentation
- Configuration options
- Advanced usage patterns
- Troubleshooting

### VS Code Extension Guide (VSCode_Extension_Guide.md)

Guide to integrating static-pdg-js with VS Code extensions. Includes:
- Installation in VS Code extensions
- Two integration patterns (direct process and server-based)
- Example extension code
- Best practices for extension development

### Example Documentation (SAMPLE_README.md)

Documentation for the example files included in the `examples/` directory. Shows:
- How to use the sample.js file
- How to run the visualization scripts
- How to interpret the output files
